Remote API documentation

This page IS the API — every button above just calls one of these routes. Any other device on the network can POST the same JSON to draw on the __WIDTH__x__HEIGHT__ matrix. Base URL: http://__IP__/

GET/info
{
  "width": __WIDTH__,
  "height": __HEIGHT__
}
GET/grid

Current canvas, one hex color per pixel.

{
  "d": [["#000000", "#ffffff", ...], ...]
}
POST/background
{
  "color": "#003366"
}
POST/clear

No body needed — resets to black.

POST/pixel
{
  "color": "#ffffff",
  "pts": [[5, 5], [6, 5]]
}
POST/fill

Flood fill from x/y, like the fill tool above.

{
  "x": 5,
  "y": 5,
  "color": "#ffffff"
}
POST/line
{
  "x0": 2,
  "y0": 2,
  "x1": 20,
  "y1": 10,
  "color": "#ffffff"
}
POST/rect

Include either or both colors.

{
  "x0": 2,
  "y0": 2,
  "x1": 20,
  "y1": 10,
  "border_color": "#ffffff",
  "fill_color": "#ff0000"
}
POST/circle

x/y is the center. Include either or both colors.

{
  "x": 16,
  "y": 16,
  "radius": 8,
  "border_color": "#ffffff",
  "fill_color": "#ff0000"
}
POST/text

font_size is one of "mini", "small", "large". Give x/y for an exact position, or align/valign with an optional padding (ignored on "center").

{
  "text": "Hello",
  "font_size": "small",
  "color": "#ffffff",
  "align": "center",
  "valign": "center"
}
GET/saves

List of saved names.

["mydrawing", "another"]
POST/save
{
  "name": "mydrawing"
}
POST/load
{
  "name": "mydrawing"
}
POST/delete
{
  "name": "mydrawing"
}

Colors are #RRGGBB hex strings. The display only holds 16 at once; past that, the least recently used custom color gets reassigned. Drawing is additive; POST /background or /clear first for a clean frame.
